**Welcome to noveraOS**
noveraOS is a full-feature operating environment, currently supported by all major operating systems, shipping with application suites for productivity and creativity. Games and/or Applications developed in Game Studio or Application Studio support all current and future releases, and will automatically comply with any system-wide design languages or features that are enabled down the road.

**Future**
noveraOS is also being developed as a standalone operating system with a custom kernel, not Linux, that will bring the same power and control of noveraOS as an environment to any computer with a supported architecture.

Other future goals include cloud-enabled accounts/directories, enabling users to access their files, folders, games and apps across all of their devices.

**Current Release**
The current release of noveraOS is a _Developer Preview_ intended to allow those interested in developing applications and games for the platform to begin to learn, and subsequently develop software with the included environments. noveraOS' Game Studio and App Studio includes an approachable Visual Scripting language, paired with a WYSIWYG designer, that enables developers of all skill levels to bring their vision to life.
